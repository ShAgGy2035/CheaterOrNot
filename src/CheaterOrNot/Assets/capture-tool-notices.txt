FFmpeg
Project/source: https://ffmpeg.org/
Build distribution/scripts: https://github.com/FFmpeg-Builds/FFmpeg-Builds
The selected unmodified Windows shared build is LGPL v3, not the GPL/nonfree
variant. Its LICENSE.txt and documentation remain in the encoder directory.
The encoder is a separate executable; its shared libraries are not statically
linked into this app. libopenh264 encodes H.264 and AAC encodes game audio.
Official public publish outputs do not contain FFmpeg or other capture-tool
binaries. On first use, the app downloads the verified upstream archive
directly, records its release URL, size and SHA-256, and keeps its upstream
license files. Do not redistribute a configured tools directory.

7-Zip
Project/source: https://www.7-zip.org/
Release source: https://github.com/ip7z/7zip/releases/tag/26.06
The extracted distribution includes its original License.txt and readme.txt.
The reduced 7zr bootstrap is public domain; full 7-Zip has additional licensing
conditions, including the unRAR restriction. Preserve the upstream files.

The active tools/capture-tools.json records component download URLs, release
tags, archive sizes and SHA-256 digests. Upstream executables are unmodified.
Steam and CS2 are not included and must be obtained separately from Valve.

PUBLIC PUBLISHES MUST NOT INCLUDE CAPTURE-TOOL BINARIES.
The app deliberately excludes FFmpeg, CS Demo Manager and 7-Zip components
from release artifacts so users obtain those components from their upstream
releases instead of receiving redistributed copies from this project.
Never distribute tools/data, credentials, imported demos or review-videos.
